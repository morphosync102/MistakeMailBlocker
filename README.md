# Gmail誤送信防止 Chrome拡張機能

Outlookのメール誤送信防止マクロをGmail用のChrome拡張機能として実装したものです。

## 機能

- **送信元チェック**: 社外へ個人アドレスから送信していないかを確認
- **送信先チェック**: 社内/社外の宛先を確認
- **件名チェック**: 件名が空でないかを確認
- **添付ファイルチェック**: 
  - 「添付」などのキーワードがあるのにファイルがない場合に警告
  - 社外向けメールでZIPファイル以外の添付がある場合に警告
  - 社外向けメール送信時にZIPファイルのパスワード保護を確認
- **送信確認ダイアログ**: 2段階の確認ダイアログ
- **送信コード**: 社外向きメールには4桁の送信コード入力が必要
- **時間帯による警告色**: 時間帯によって警告の背景色が変化

## 技術スタック

- **TypeScript**: 型安全な開発
- **React**: モダンなUIコンポーネント
- **TailwindCSS**: ユーティリティファーストのスタイリング
- **Vite**: 高速なビルドツール

## インストール方法

### 1. ビルド

```bash
npm install
npm run build
```

### 2. Chrome拡張機能として読み込み

1. Chromeで `chrome://extensions/` を開く
2. 右上の「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. プロジェクトの `dist` フォルダを選択

## 設定

### 自社ドメインの設定

`src/utils.ts` の `COMPANY_DOMAINS` 配列を編集して、自社のドメインを設定してください:

```typescript
const COMPANY_DOMAINS = ['example.com', 'yourcompany.com'];
```

## 開発

### 開発モード

```bash
npm run dev
```

ファイル変更を監視して自動的に再ビルドされます。変更後はChrome拡張機能の管理ページで拡張機能を再読み込みしてください。

### ビルド

```bash
npm run build
```

## 注意事項

- この拡張機能はGmailのDOM構造に依存しているため、Gmailのアップデートにより動作しなくなる可能性があります
- ZIPファイルのパスワード保護はブラウザ上では確認できないため、警告のみ表示されます
